# CALCULA Colony

**CALCULA is a research and design package for a proposed multi-agent governance framework.**

## Current repository state

## Evidence boundary for the roadmap

The status block below is a historical planning snapshot, not current implementation evidence. As of 2026-10-09, this repository contains the research/design documents listed here but no executable CALCULA engine or reproducible test suite. Earlier statements that an engine or tests existed must not be treated as current verified implementation until versioned source code and repeatable CI evidence are present in this repository.


The live repository contains essays, a whitepaper, a roadmap, attribution material, and license files.

The current repository does not contain an executable CALCULA engine, a Rust AETHEL Safety Kernel, a deployed colony runtime, or a production transaction system.

## The design

The CALCULA model describes a seven-role conceptual colony and a composite evaluation score across six dimensions:

| Dimension | Weight |
|---|---:|
| Flourishing | 25% |
| Harm Reduction | 20% |
| Equity | 20% |
| Regenerative Capacity | 15% |
| Cooperation | 12% |
| Beauty | 8% |

The weights sum to 100%. They are a proposed evaluation model, not an independently validated scientific law.

The MANNA design described by the project is 84% Community, 15% Crew, and 1% Architect. This is a project-design allocation, not evidence of a live payment protocol.

## Agent material

The repository contains essay/document material for seven conceptual roles. Scores such as 0.916 or individual LQ values in older documentation are documentation artifacts unless tied to a reproducible scoring implementation and evidence record in this repository.

## Security and governance language

The AETHEL Safety Kernel belongs to the broader portfolio architecture, but the current CALCULA repository does not ship that kernel. Statements such as structurally incapable of capture should therefore be treated as design intent, not as an established security property.

## Roadmap

Implementation requires a reproducible engine, explicit schemas, executable invariants, independent testing, and externally verifiable deployment evidence.
